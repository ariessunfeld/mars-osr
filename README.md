# Mars OSR

[![DOI](https://zenodo.org/badge/1350224149.svg)](https://doi.org/10.5281/zenodo.22168117)

Mars OSR is research software for simulating and designing orbits and
trajectories for orbiting solar reflectors at Mars.

Mars OSR can be used to find Earth-escape and Mars-capture solar-sail
trajectories, design interplanetary transfers and stitch trajectory segments
together, identify and optimize periodic orbits for solar sails at Mars,
demonstrate long-term orbital stability, and reconcile stationkeeping
requirements with illumination of a selected location on the surface of Mars.
The software accompanies the arXiv manuscript *Doubling Sunlight at a Human
Mars Base Using Orbiting Solar Reflectors*.

## Scientific scope

The Mars optical path in this release is **vacuum only**. Delivered-flux and
fluence calculations use unit transmission. The repository does not implement
Mars atmospheric extinction, scattering, radiative transfer, or climate
response. See [docs/model_scope.md](docs/model_scope.md) before interpreting an
illumination result.

The release includes:

- Mars-centred orbital dynamics with zonal or MRO120F gravity;
- solar-radiation pressure, shadowing, and finite-slew attitude dynamics;
- sun-synchronous orbit, visibility, beam-footprint, and constellation tools;
- Earth escape with an Earth density/drag model;
- Mars escape and time-reversed capture workflows;
- Sun-centred Earth-to-Mars cruise dynamics and trajectory optimization; and
- fast unit and integration tests plus opt-in slow physical regressions.

Earth atmospheric density and drag are retained solely for the low-Earth-orbit
escape calculation. They are unrelated to Mars optical transmission.

## Installation

The supported environment is Python 3.12 on macOS or Linux. With conda or
mamba:

```bash
conda env create -f environment.yml
conda activate mars-osr
python -m pip install -e . --no-deps
```

For a minimal pip installation:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -e .
```

The trajectory solvers that use IPOPT require the optional `optimization`
dependencies and a system IPOPT installation. The conda environment includes
them.

## Required scientific data

NAIF SPICE kernels and the MRO120F gravity field are downloaded rather than
versioned. The complete kernel set is about 1.2 GB:

```bash
python scripts/fetch_kernels.py
```

The gravity field is fetched from its PDS archive on first use and validated
against the expected MRO120F header values. Kernel download locations are
defined in the source, and their SHA-256 values are recorded locally after
download. The entire `data/` directory is ignored by Git. A source checkout
stores downloads under `data/`; an installed wheel uses `~/.cache/mars-osr/`.
Set `MARS_OSR_DATA_DIR` to choose a different common data root.

## Tests

After fetching the kernels:

```bash
pytest                  # fast suite (slow tests excluded by default)
pytest -m slow          # slow physical regressions
pytest -m ''            # complete suite
```

Each slow test takes at least 30 seconds. Some representative workflows run
for hours or generate large outputs; they are not smoke tests.

## Representative workflows

```bash
# Vacuum illumination-window feasibility at the default Mars design point
python scripts/illumination_window_feasibility.py

# Generate the frozen constellation design into simulation_outputs/
python scripts/generate_walker_constellation.py

# Mars escape or time-reversed Mars capture
python scripts/run_srp_escape.py
python scripts/run_srp_capture.py

# Drag-aware Earth escape
python scripts/run_srp_escape_earth.py
```

The interplanetary commands require the Earth-escape summary and Mars capture-node
JSON generated by the workflows above. Run `--help` for their required
arguments and solver controls.

Generated files go under `simulation_outputs/`, which is intentionally ignored.
No simulation output is embedded in this repository. See
[docs/reproducibility.md](docs/reproducibility.md) for the release's
reproducibility contract.

## Manuscript figures

The exact figure files used by the manuscript are archived under
[`figures/manuscript/reference`](figures/manuscript/reference). A
machine-readable registry maps each figure to its producer, inputs, reference
hash, and reproduction status. The required simulation products are distributed
as a separate release asset rather than committed to Git.

```bash
python -m pip install -e ".[figures]"
python scripts/fetch_manuscript_figure_data.py --archive /path/to/mars-osr-manuscript-figure-data-v1.tar.gz
python scripts/reproduce_manuscript_figures.py --list
python scripts/reproduce_manuscript_figures.py --figure 7
```

Figures 2–8 and S1–S4 can be regenerated from the archived inputs. Figure 1 is
a manual concept illustration. Figures 9 and 10 currently include their
reference images and plotting layers; their canonical atmospheric-transmission
and climate-model generation package will be added after the coauthor handoff.
See the [figure reproduction guide](figures/manuscript/README.md) for details.
